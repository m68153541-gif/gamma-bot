# A-Gamma — Telegram-бот с ИИ

Бот на aiogram + Gemini: свободно общается на любые темы, решает задачи по фото и тексту
(математика, геометрия, физика, гуманитарные предметы) с подробными пошаговыми решениями.

## Возможности

- 💬 разговор на любые темы с памятью последних 8 пар сообщений (`/reset` — сброс);
- 📸 фото и файлы-картинки: бот переписывает условие, решает по шагам, выделяет **Ответ**;
- 😈 `/dir` — агрессивный режим, `/andir` — вернуть спокойный (по умолчанию спокойный);
- 📖 `/vopros` — рассказ о боте, `/help` — справка;
- 🔁 автоматический выбор модели: если основная недоступна, берётся резервная.

## Локальный запуск

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
# вписать TELEGRAM_BOT_TOKEN и GEMINI_API_KEY
python bot.py
```

Windows-заметка: ставьте зависимости с флагом `--only-binary :all:`, если pip пытается
собирать колёса из исходников на 32-битном Python.

## Переменные окружения

| Переменная | Обязательна | Что делает |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | токен из `@BotFather` |
| `GEMINI_API_KEY` | да | ключ Google AI Studio |
| `MODELS` | нет | список моделей через запятую, первая — основная |
| `HISTORY_TURNS` | нет | сколько пар сообщений помнить (по умолчанию 8) |
| `COOLDOWN_SECONDS` | нет | пауза между запросами одного пользователя |
| `MAX_IMAGE_MB` | нет | максимальный размер фото |
| `PORT` | нет | если задан — поднимается HTTP-сервер с `/health` (для Render) |

## Деплой на Render (бесплатно)

1. Запушьте репозиторий на GitHub (публичный или приватный).
2. В Render: **New → Blueprint**, выберите репозиторий — Render прочитает `render.yaml`.
3. Впишите `TELEGRAM_BOT_TOKEN` и `GEMINI_API_KEY` в разделе **Environment** сервиса
   (в репозитории их нет и быть не должно).
4. Дождитесь первого билда: в логах должно появиться `Бот запущен` и `Start polling`.

### Важно про бесплатный тариф Render

- бесплатный **web service** засыпает после 15 минут без входящего HTTP-трафика;
  пока сервис спит, бот не отвечает;
- чтобы не засыпал, нужен внешний пингер (например cron-job.org или UptimeRobot):
  раз в 5–10 минут дёргать `https://<ваш-сервис>.onrender.com/health`;
- настоящий режим 24/7 без костылей — платный **Background Worker** (около $7/мес),
  ему не нужен `PORT` и пингер;
- бесплатный инстанс могут перезапустить в любой момент: память диалога в памяти процесса
  при этом очистится.

## Безопасность

- токены и ключи — только в переменных окружения, `.env` в `.gitignore`;
- при утечке токена: `@BotFather` → `/revoke`, ключ Gemini — перевыпустить в AI Studio;
- бот не хранит данные на диске, история диалогов живёт только в памяти процесса.
